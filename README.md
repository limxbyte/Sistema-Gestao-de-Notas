# Sistema de Gestão de Notas

Projeto acadêmico desenvolvido em Python como parte dos meus estudos em Engenharia de Software.

## Sobre o projeto

O sistema recebe as notas de um aluno, calcula a média aritmética e informa se ele foi aprovado de acordo com a média mínima definida.

## Tecnologias utilizadas

- Python 3
- Google Colab

## Conceitos praticados

- Variáveis e tipos de dados
- Listas
- Estruturas de repetição
- Estruturas condicionais
- Funções e cálculos de média

## Como executar

O arquivo do projeto está disponível neste repositório no formato `.ipynb` e pode ser aberto no Google Colab.

## Objetivo

Praticar lógica de programação e desenvolver habilidades fundamentais em Python.
